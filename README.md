# 光球绕行（Light Orb Orbit）

一款极简像素风的肉鸽（Roguelike）动作游戏，纯前端实现，无需安装、无需构建。

你操控一颗**光球**，环绕行星在**地表行走**或**飞行**，收集资源输送回主恒星，拾取临时装备对抗追踪你的**黑球敌人**，攒够资源后击败**恒星守护者（Boss）**，跃迁到下一个星系。共 6 个星系，难度逐级递增。

## 特性

- 环形轨道移动：行走 / 飞行双模式（飞行消耗魔法）
- 血量 / 魔法 / 护盾三资源
- 自动攻击 + 追踪玩家的黑球敌人
- 资源收集与上缴、5 种武器 + 5 种被动（装备星系间清零）
- 多武器栏：钻石扩充「攻击类装备栏」，可同时携带多把武器自动齐射
- 星系间升级：生命上限 / 魔法上限 / 护盾量 / 攻击强化 / 恢复速度 / 攻击装备栏
- 图鉴：记录旅途中遇到的敌怪与装备
- 普通 / 困难双模式：困难模式刷怪更慢，但敌怪会弹幕射击，恒星守护者追加蓝色激光
- 6 星系 + Boss 战，程序化地形与难度缩放
- WebAudio 程序化音效、像素光晕与粒子特效

## 运行

直接用浏览器打开 `wenx遇星.html` 即可（纯前端、零依赖、`file://` 可运行）。

或启动一个本地静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 操作

| 按键 | 作用 |
|---|---|
| `←` `→` / `A` `D` | 绕行星移动 |
| `↑` / `W` / 空格 | 跳跃 · 上升 |
| `↓` / `S` | 下降 |
| `Shift` / `F` | 切换 飞行/行走 |
| `P` / `Esc` | 暂停 |
| `M` | 静音 |

攻击为**自动射击**：目标进入射程即自动开火。

## 技术

HTML5 Canvas + 原生 JavaScript，无框架、无构建工具、无外部资源。

## 目录结构

```
index.html          画布 + HUD + 界面覆盖层
style.css           像素风样式
js/
  config.js         参数、武器/被动、升级、6 星系难度表
  util.js           数学 / 随机 / 极坐标工具
  input.js          键盘鼠标输入
  audio.js          WebAudio 程序化音效
  entities.js       光球 / 敌人 / Boss / 资源 / 装备 / 子弹
  galaxy.js         行星与地形生成、刷怪、难度缩放
  render.js         渲染管线
  main.js           状态机与主循环
```
